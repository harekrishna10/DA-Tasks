## Data Analytics Task

This repository contains my **Data Analytics (DA) task/project** completed as part of my learning and portfolio development.

### Project Overview

The objective of this task is to analyze the dataset, clean the data, perform exploratory data analysis (EDA), and generate meaningful business insights using Python and data visualization tools.
